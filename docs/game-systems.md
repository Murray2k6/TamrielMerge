# Game systems checklist

Everything each game has inside it, from UESP, Daggerfall Unity and OpenMW research (2026-10-07), against what
TamrielMerge converts. Status: **done**, **partial**, **missing**, or **n/a** (the game doesn't have it).
Numbers marked (u) are unverified; settings should be read from the game's own master files (GMST) when built.

## Redguard's cutscene lockouts (2026-11-05)

Redguard's scripts nest lockoutPlayer(1/0) (TMRgState.Lockout counts them; controls come back when the last lets go).
Redguard's engine ends them all on a map change: its opening, START's SCENEST, locks Cyrus out and never lets go, the
island's load does. Here too: LoadWorld and every journey between times and places (TMStoryOrder.TravelTo,
TravelToOffset) call TMRgState.MapChanged, which releases them (user: "redguard i still cant move when npcs can").
Each lockout change is logged ("[TamrielMerge] Redguard lockout TRUE by <script>: 1 held"), so a hold that remains
names its script. The island's arrival, BOATSTAR, locks for about 28 s while the boat comes in and writes Cyrus's first
three log entries ($082, $084, $001) before letting go.
